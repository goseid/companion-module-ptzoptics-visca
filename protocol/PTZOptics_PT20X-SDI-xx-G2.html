PTZOptics PT20X-SDI-xx-G2 Protocol Info

This document contains information about the VISCA Protocol for the following cameras:

  • PT20X-SDI-GY-G2
  • PT20X-SDI-WH-G2 V1.5

qq: B_Gain (bytes 2–3)
r: WB Mode (byte 4)
s: Sharpness (byte 5)
tt: AE Mode (byte 6)
u.bit2: Back Light (byte 7)
u.bit1: Exposure Comp (byte 7)
vv: Shutter Position (byte 8)
ww: Iris Position (byte 9)
yy: Gain Position (byte 10)
xx: Bright Position (byte 11)
z: Exposure Comp. Position (byte 12)

CAM_EnlargementBlockInq81 09 7E 7E 03 FF90 50 00 00 00 00 00 00 00 0p 0q rr 0s 0t 0u FFp: AF Sensitivity (byte 7)
q.bit0: Picture Flip (byte 8; 1=On, 0=Off)
rr.bit6~3: Color Gain (byte 9; 0h(60%) to Eh(200%))

t.bit2~0: NR2D Level (byte 11)
